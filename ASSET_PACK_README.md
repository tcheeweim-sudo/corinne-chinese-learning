# Corinne's 中文 Tiger V0.3.1 Visual Asset Pack

This pack mirrors the approved Google Drive production assets.

## Usage

Extract the contents into the repository root on branch:

`codex/v0.3.1-visual`

The resulting paths should begin with:

- `assets/reference/`
- `assets/tiger/poses/`
- `assets/tiger/house/`
- `assets/tiger/items/`
- `assets/tiger/icons/`

Do not treat `house-room-reference.png` or the files in `assets/reference/` as runtime artwork.
They are implementation/design references.

Runtime Tiger House should use:
- `assets/tiger/house/house-room-empty.png`
- individual furniture/item PNGs
- `assets/tiger/poses/tiger-house.png`

The wearable alignment reference is for positioning the ribbon and hat over `tiger-house.png`.
