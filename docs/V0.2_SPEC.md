# V0.2 Product Specification

## Goal
Turn V0.1 into a simpler, more child-led daily Chinese practice experience for Corinne, a Singapore Primary 1 student taking standard Chinese using 欢乐伙伴 2.0.

V0.2 should improve engagement without expanding into a large learning platform.

## Product principles
- One guided daily flow, not a menu of learning modes.
- Roughly 5 minutes per daily mission.
- School 听写 is the immediate priority.
- MOE P1 standard Chinese provides the curriculum backbone.
- Personal mastery determines revision priority.
- Rewards should motivate practice without becoming manipulative.
- Keep the app static, local-first and usable offline.

## 1. Child-facing experience

### Home
The home screen should be much simpler than V0.1.

Show:
- Tiger mascot
- "Today's mission"
- one progress indicator
- current coin balance
- one large START button
- a small Tiger House button

Do not show Learn, Write, Recall and Rewards as four equal choices on the main screen.

### Guided mission
A normal session should flow automatically through:
1. See and hear
2. Listen and recognise
3. Write required characters
4. Recall
5. Reward

Use the current weekly 听写 items first.

### Parent access
Keep parent analytics, but hide them from the normal child flow behind a subtle grown-up/settings entry.

## 2. Tiger theme

Replace BaoBao/panda with a tiger mascot inspired by Corinne's real tiger plush.

Visual direction:
- soft pastel palette
- warm cream, peach, muted orange, light brown
- rounded shapes
- gentle claymation/plush feel
- expressive anime-like face
- calm rather than arcade-like
- avoid noisy neon UI

Do not copy any copyrighted commercial tiger character.

## 3. Reward loop: Tiger House

Coins become spendable.

Initial V0.2 shop should contain only a small starter set, for example:
- bed
- pillow
- rug
- lamp
- plant
- wall picture
- toy basket
- small hat or ribbon for Tiger

Requirements:
- every item has a coin price
- purchased items persist locally
- child can place/equip simple items using preset positions, not free-form drag-and-drop
- purchased items remain available permanently
- no random loot boxes
- no real money
- no ads
- no premium currency

Keep stars only if they remain useful. If they duplicate coins, simplify rather than add more currencies.

## 4. Audio: fix as a blocker

V0.1 browser speech produced no sound on the Samsung device.

Do not rely only on Web Speech API.

Implement a local audio system:
- support bundled audio files for curriculum/spelling items
- preload only what is needed
- work offline once installed
- provide a browser TTS fallback when available
- fail gracefully if neither source works

For V0.2, bundle audio for the current 23 Sept 听写 items at minimum:
- 妈妈
- 爸爸
- 一公斤
- 你们
- 她不会去
- 我会打球
- 他们是我的父母

If generating or obtaining pronunciation audio is not possible inside Codex, implement the audio abstraction and clearly identify the exact audio filenames still required. Do not silently retain broken TTS as the primary path.

## 5. Content architecture

Model three layers separately.

### A. MOE curriculum
Source: Singapore MOE, Primary 1 standard Chinese character list for the 2024 syllabus.
Official source:
https://www.moe.gov.sg/-/media/files/primary/syllabus/2024-character-list-primary-one-chinese.pdf

For each lesson store:
- lesson number
- volume: 1A or 1B
- recognition characters (我会认)
- writing characters (我会写)
- source = MOE

Do not expose the full curriculum to Corinne as a long list.

### B. School 听写
For each spelling set store:
- test date
- lesson if known
- phrase/sentence
- pinyin
- meaning if useful
- source = school
- active/archived status

Current active set is 听写（十六）, 23 Sept:
1. 妈妈
2. 爸爸
3. 一公斤
4. 你们
5. 她不会去
6. 我会打球
7. 他们是我的父母

This aligns with Lesson 16 writing requirements such as:
父 母 她 他 会 你 们 爸 妈 打

### C. Corinne mastery
Track:
- question attempts
- first-attempt correctness
- successful writing repetitions
- last practised
- current mastery by item/character
- weak items

## 6. Daily selection logic

For V0.2 keep logic understandable.

Priority order:
1. active upcoming school 听写
2. characters required to write for the associated MOE lesson
3. weak items from previous practice
4. recognition-only revision

Do not attempt sophisticated adaptive algorithms yet.

## 7. Writing

Preserve the working V0.1 Hanzi Writer implementation.

Keep:
- character-by-character practice
- stroke-order animation
- stroke validation
- S Pen/finger support
- local character data
- hints after mistakes
- responsive orientation handling

Do not weaken writing validation merely to make the game easier.

## 8. Parent view

Keep concise metrics:
- active 听写 set
- practice sessions
- first-attempt accuracy
- writing repetitions
- weak items
- mastery by spelling item/character
- current streak

Add a simple indication of which MOE lesson the current 听写 maps to when known.

## 9. Data and privacy

- no account
- no cloud profile
- no analytics service
- no advertising
- no third-party child tracking
- all progress stays local in V0.2

## 10. Technical constraints

Keep:
- static PWA
- GitHub Pages
- no backend
- no framework migration unless there is a compelling technical reason
- minimal dependencies
- offline app shell
- bundled Hanzi Writer assets/data
- responsive phone and Samsung tablet layouts

Refactor only where needed to support maintainability.

Recommended data separation:
- curriculum/moe-p1-standard.js or JSON
- curriculum/tingxie.js or JSON
- app/progress state
- shop/tiger-house catalogue

## 11. Migration

Preserve existing V0.1 local progress where practical.

If the state schema changes:
- implement a migration
- do not crash on old or malformed storage
- document any metrics that cannot be reconstructed

## 12. Tests

Retain V0.1 validation and add checks for:
- audio fallback behaviour
- guided mission flow
- Tiger House purchase cannot overspend
- purchase persists after reload
- same item cannot be charged twice
- current 听写 prioritisation
- curriculum data references valid characters
- offline shell still works
- existing mission anti-farming
- streak behaviour
- Hanzi Writer character data availability

## 13. Out of scope for V0.2

Do not add:
- OCR/photo extraction
- AI-generated questions
- cloud sync
- accounts
- leaderboards
- social sharing
- ads
- real-money purchases
- large numbers of game modes
- complex room editing
- P2 or higher curriculum

## Acceptance criterion
V0.2 succeeds if Corinne can open the app, understand what to do without adult explanation, complete roughly 5 minutes of meaningful Chinese practice, earn coins, and use those coins to improve her Tiger House.

The app should feel simpler than V0.1, not more feature-heavy.
