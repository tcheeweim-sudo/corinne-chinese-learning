# Required pronunciation files

The V0.2 audio controller looks for these files before using browser Mandarin speech:

- `mama.mp3`
- `baba.mp3`
- `kg.mp3`
- `nimen.mp3`
- `taqu.mp3`
- `daqiu.mp3`
- `fumu.mp3`

They are intentionally absent until high-quality, appropriately licensed Mandarin recordings are supplied. Do not replace them with fabricated pronunciation.
